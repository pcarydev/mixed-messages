
# Mixed Messages

## Description
Mixed Messages is a JavaScript program that generates random messages each time it runs. The messages take the form of humorous fortunes for programmers.

## How It Works
The program stores different message components in an object containing three arrays:

- **Subjects:** The subject of the fortune.
- **Predictions:** What the subject is predicted to do.
- **Endings:** An additional phrase that completes the fortune.

The program randomly selects one element from each array and combines them to create a unique message.

## Technologies Used
- JavaScript
- Node.js

## How to Run
1. Clone this repository.
2. Navigate to the project directory.
3. Run the following command in your terminal:

   ```bash
   node script.js
   ```

4. A randomly generated programmer's fortune will appear in the console.
